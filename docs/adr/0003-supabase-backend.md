# Supabase Auth e Postgres para o MVP

Em 2026-11-07 o usuário aprovou Supabase Auth para identidade e Postgres para
persistência, mantendo Cloudflare na hospedagem. A escolha reduz o trabalho de
construir autenticação e integridade sobre Apps Script/Sheets ou Workers/D1.
RLS por vitrine e testes de isolamento são requisitos, não benefícios automáticos.
Pausa, cotas, email e backup do plano gratuito exigem acompanhamento. O método
de login e a configuração da conta ainda serão definidos; nenhum projeto remoto
foi criado por esta decisão.
